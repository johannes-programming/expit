Introduction
------------

This project provides an implementation of the ``expit`` function.

Installation
------------

To install ``expit``, you can use ``pip``.
Open your terminal and run:

.. code-block:: shell

    pip install expit

Typing
------

The typing conforms strictly to ``mypy``.

.. container:: versionadded

    **Added in version 1.1.**

Features
--------

``expit.core``
~~~~~~~~~~~~~~

The functions in ``expit.core`` can also be imported from ``expit`` directly.

``expit.core.function(x: float, /) -> float``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

This function implements ``expit``.

``expit.core.main(args: Iterable[str] | None = None) -> int``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

The project provides a command-line interface that can also be accessed from within Python.
For more information, read the help message:

.. code-block:: shell

    python3 -m expit -h

.. code-block:: python

    import expit
    expit.main(['-h'])

``expit.core.parse_args(args: Iterable[str] | None = None) -> Namespace``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

.. container:: versionadded

    **Added in version 1.2.**

``expit.core.run(x: float) -> None``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

.. container:: versionadded

    **Added in version 1.2.**

``expit.tests``
~~~~~~~~~~~~~~~

``expit.tests.test() -> unittest.TextTestResult``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

This project can be tested through its ``test`` function.

The following code can also be executed by running the project's ``run_tests.py``:

.. code-block:: python

    import expit.tests
    expit.tests.test()

Example
-------

To calculate the function value of ``0.42`` in the shell:

.. code-block:: shell

    py -m expit 0.42

Or inside of a Python script:

.. code-block:: python

    import expit
    print(expit.function(0.42)) #0.6034832498647263
